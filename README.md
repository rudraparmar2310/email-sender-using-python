# 📧 Email Sender Using Python

A desktop-based email sender application built with **Python** and **Tkinter** that allows users to send emails through Gmail's SMTP server using a simple graphical user interface. The application validates user inputs, authenticates securely using an App Password, supports optional file attachments, and provides real-time success or failure notifications.

This project demonstrates Python GUI development, SMTP email communication, input validation, and file handling, making it a great beginner-friendly networking and desktop application project.

---

## 🚀 Features

- 📧 Send emails using Gmail SMTP
- 🖥️ User-friendly Tkinter GUI
- 🔐 Secure authentication using Gmail App Password
- ✅ Input validation for email fields
- 📎 Optional file attachment support
- 📝 Compose email subject and message
- ⚠️ Error handling with status notifications
- ✔️ Success and failure pop-up messages
- 🎨 Clean and intuitive desktop interface

## ⚙️ How It Works

1. Enter the sender's Gmail address.
2. Enter the Gmail App Password.
3. Enter the recipient's email address.
4. Add the email subject.
5. Write the email message.
6. Optionally attach a file.
7. Click **Send**.
8. The application authenticates with Gmail's SMTP server and sends the email.
9. A success or error message is displayed.

## 🔑 Gmail App Password Setup

To use this application with Gmail:

1. Enable **2-Step Verification** on your Google account.
2. Generate an **App Password** from your Google Account settings.
3. Use the generated App Password instead of your Gmail account password.

> **Note:** Regular Gmail passwords are not supported for SMTP authentication.
